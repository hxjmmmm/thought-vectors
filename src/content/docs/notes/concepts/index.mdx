### 学习路径建议

**入门**（无 ML 基础）：Embedding → Tokenization → 激活函数 → 损失函数 → 反向传播

**进阶**（已学 Transformer）：注意力机制 → Multi-Head → 位置编码 → LayerNorm → 优化器

**实战**（部署优化）：KV Cache → Flash Attention → 模型量化 → 正则化
