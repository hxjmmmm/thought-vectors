## Flash Attention

Flash Attention 是让大模型推理和训练加速的关键技术，**在不牺牲精度的情况下，将注意力计算加速 2-4 倍，显存降低 5-20 倍**。

### 为什么标准 Attention 慢？

标准 Attention 的计算瓶颈不是计算本身，而是 **GPU 显存读写**：

```mermaid
flowchart LR
    A[GPU 计算单元<br/>很快] --> B[显存 HBM<br/>很慢]
    B --> A
```

标准 Attention 需要反复读写大型矩阵（QK^T 和 Softmax 结果），大量时间浪费在数据传输上。

### 核心思想：分块计算

Flash Attention 将 Q、K、V 分成小块，在 GPU 的 SRAM（快缓存）中完成计算，避免频繁读写 HBM：

```mermaid
flowchart TD
    subgraph 标准 Attention
    A1[QK^T → HBM] --> A2[Softmax → HBM] --> A3[×V → HBM]
    end
    subgraph Flash Attention
    B1[分块加载到 SRAM] --> B2[块内计算] --> B3[增量更新输出]
    end
```

### 在 HuggingFace 中使用

```python
from transformers import AutoModelForCausalLM

# 自动使用 Flash Attention 2
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3.2-3B",
    torch_dtype=torch.bfloat16,
    attn_implementation="flash_attention_2",
)
```
