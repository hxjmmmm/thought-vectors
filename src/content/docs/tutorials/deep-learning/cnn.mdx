## CNN：卷积神经网络

CNN 是处理图像等网格结构数据的核心架构。

### 卷积层

卷积核在输入上滑动，提取局部特征：

```python
import torch
import torch.nn as nn

# 一个卷积层：输入 3 通道，输出 16 通道，3×3 卷积核
conv = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1)

# 模拟一张 RGB 图片 (batch=1, 3通道, 32×32)
image = torch.randn(1, 3, 32, 32)
output = conv(image)
print(f"输出形状: {output.shape}")  # (1, 16, 32, 32)
```

### 池化层

下采样，减少参数量，增加感受野：

```python
# 最大池化：2×2 窗口，步长 2
pool = nn.MaxPool2d(kernel_size=2, stride=2)
pooled = pool(output)
print(f"池化后: {pooled.shape}")  # (1, 16, 16, 16)
```

### 经典架构：LeNet-5

```python
class LeNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 6, 5),    # 28×28 → 24×24
            nn.ReLU(),
            nn.MaxPool2d(2),        # 24×24 → 12×12
            nn.Conv2d(6, 16, 5),    # 12×12 → 8×8
            nn.ReLU(),
            nn.MaxPool2d(2),        # 8×8 → 4×4
        )
        self.classifier = nn.Sequential(
            nn.Linear(16 * 4 * 4, 120),
            nn.ReLU(),
            nn.Linear(120, 84),
            nn.ReLU(),
            nn.Linear(84, 10),
        )

    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), -1)  # 展平
        return self.classifier(x)

model = LeNet()
x = torch.randn(1, 1, 28, 28)  # MNIST 图片
print(model(x).shape)  # (1, 10) — 10 类输出
```

### 架构演进

| 架构 | 年份 | 核心贡献 |
|------|------|----------|
| LeNet | 1998 | 卷积 + 池化 + 全连接 |
| AlexNet | 2012 | ReLU + Dropout + GPU |
| VGG | 2014 | 小卷积核堆叠加深 |
| ResNet | 2015 | 残差连接，训练 152 层 |
