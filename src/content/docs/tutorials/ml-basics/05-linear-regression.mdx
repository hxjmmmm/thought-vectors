## 线性回归

线性回归是最简单的机器学习算法，但包含了所有核心概念：模型、损失函数、优化。

### 模型

假设目标值 $y$ 是特征 $x$ 的线性组合：

$$
\hat{y} = w_0 + w_1x_1 + w_2x_2 + \cdots + w_nx_n
$$

向量形式：$\hat{y} = Xw$，其中 $X$ 是 $m \times n$ 的特征矩阵，$w$ 是 $n$ 维权值向量。

### 损失函数：均方误差 (MSE)

$$
J(w) = \frac{1}{m}\sum_{i=1}^{m}(\hat{y}^{(i)} - y^{(i)})^2 = \frac{1}{m}\|Xw - y\|^2
$$

### 方法一：解析解（正规方程）

令梯度为零，直接求解：

$$
w = (X^TX)^{-1}X^Ty
$$

```python
import numpy as np

# 生成数据：y = 3x + 2 + 噪声
np.random.seed(42)
X = np.random.rand(100, 1) * 10
y = 3 * X.ravel() + 2 + np.random.randn(100) * 2

# 加偏置列
X_b = np.c_[np.ones((len(X), 1)), X]

# 正规方程
w = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
print(f"w0 (偏置) = {w[0]:.2f}, w1 (斜率) = {w[1]:.2f}")
# w0 ≈ 2, w1 ≈ 3
```

### 方法二：梯度下降

当特征很多时，解析解求逆矩阵太慢。梯度下降每次迭代更新参数：

$$
w := w - \alpha \nabla J(w)
$$

其中 $\nabla J(w) = \frac{2}{m}X^T(Xw - y)$

```python
def gradient_descent(X, y, lr=0.01, epochs=1000):
    m, n = X.shape
    w = np.zeros(n)
    history = []

    for epoch in range(epochs):
        # 预测
        y_pred = X @ w
        # 梯度
        grad = (2 / m) * X.T @ (y_pred - y)
        # 更新
        w -= lr * grad
        # 记录损失
        loss = np.mean((y_pred - y) ** 2)
        history.append(loss)

        if epoch % 200 == 0:
            print(f"Epoch {epoch:4d}: loss = {loss:.4f}")

    return w, history

# 标准化特征（梯度下降需要）
X_std = (X - X.mean()) / X.std()
X_b_std = np.c_[np.ones((len(X_std), 1)), X_std]

w_gd, history = gradient_descent(X_b_std, y, lr=0.1, epochs=1000)
print(f"\n梯度下降结果: w0 = {w_gd[0]:.2f}, w1 = {w_gd[1]:.2f}")
```

### 学习率的影响

```python
import matplotlib.pyplot as plt

for lr in [0.001, 0.01, 0.1, 0.5]:
    _, history = gradient_descent(X_b_std, y, lr=lr, epochs=100)
    plt.plot(history, label=f'lr={lr}')

plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.legend()
plt.yscale('log')
plt.title('不同学习率下的收敛速度')
plt.show()
```

### 三种梯度下降变体

| 类型 | 每步数据量 | 特点 |
|------|-----------|------|
| 批量梯度下降 | 全部数据 | 稳定，但慢 |
| 随机梯度下降 (SGD) | 1 条数据 | 快，但不稳定 |
| 小批量梯度下降 | 32-256 条 | 折中，最常用 |

```python
# 小批量 SGD
def sgd(X, y, lr=0.01, epochs=100, batch_size=16):
    m = len(X)
    w = np.zeros(X.shape[1])
    for epoch in range(epochs):
        # 随机打乱
        idx = np.random.permutation(m)
        X_shuffled, y_shuffled = X[idx], y[idx]
        # 小批量迭代
        for i in range(0, m, batch_size):
            X_batch = X_shuffled[i:i+batch_size]
            y_batch = y_shuffled[i:i+batch_size]
            grad = (2 / len(X_batch)) * X_batch.T @ (X_batch @ w - y_batch)
            w -= lr * grad
    return w
```

### 线性回归的局限

- 假设特征和目标之间是线性关系
- 对异常值敏感
- 特征之间高度相关时（多重共线性）不稳定

### 总结

线性回归虽然简单，但涵盖了机器学习的完整流程：**模型定义 → 损失函数 → 梯度优化 → 预测**。理解了这个流程，就能理解所有更复杂的模型。
