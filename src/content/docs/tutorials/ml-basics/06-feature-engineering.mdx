## 特征工程

> 数据和特征决定了机器学习的上限，模型和算法只是逼近这个上限。

特征工程是把原始数据转换成模型能理解的形式。好的特征胜过复杂的模型。

### 数据清洗

#### 处理缺失值

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "age":    [25, np.nan, 35, 28, np.nan],
    "salary": [50000, 60000, np.nan, 55000, 70000],
    "city":   ["北京", "上海", None, "北京", "深圳"],
})

# 查看缺失情况
print(df.isnull().sum())

# 数值列：填充均值
df["age"] = df["age"].fillna(df["age"].mean())
df["salary"] = df["salary"].fillna(df["salary"].median())

# 类别列：填充众数
df["city"] = df["city"].fillna(df["city"].mode()[0])

print(df)
```

#### 处理异常值

```python
# IQR 方法检测异常值
Q1 = df["salary"].quantile(0.25)
Q3 = df["salary"].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

# 筛选正常范围内的数据
df_clean = df[(df["salary"] >= lower) & (df["salary"] <= upper)]
print(f"去掉 {len(df) - len(df_clean)} 个异常值")
```

### 特征缩放

不同特征的数值范围差异很大（如年龄 0-100，收入 0-100000），需要缩放到同一尺度。

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

X = np.array([[25, 50000], [30, 80000], [35, 120000]])

# 标准化：均值 0，标准差 1
scaler = StandardScaler()
X_std = scaler.fit_transform(X)
print(f"标准化:\n{X_std}")
print(f"均值: {X_std.mean(axis=0)}, 标准差: {X_std.std(axis=0)}")

# 归一化：缩放到 [0, 1]
scaler = MinMaxScaler()
X_norm = scaler.fit_transform(X)
print(f"归一化:\n{X_norm}")
```

### 类别编码

```python
from sklearn.preprocessing import OneHotEncoder, LabelEncoder

# Label Encoding：类别 → 整数
cities = ["北京", "上海", "深圳", "北京", "上海"]
le = LabelEncoder()
labels = le.fit_transform(cities)
print(f"Label 编码: {list(zip(cities, labels))}")

# One-Hot Encoding：每个类别单独一列
import pandas as pd
df = pd.DataFrame({"city": cities})
df_encoded = pd.get_dummies(df, columns=["city"])
print(df_encoded)
```

### 特征选择

不是所有特征都有用。太多无关特征会降低模型性能。

```python
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.datasets import make_classification

# 生成 10 个特征的数据，只有 3 个真正有用
X, y = make_classification(n_samples=200, n_features=10,
                           n_informative=3, random_state=42)

# 选择最好的 5 个特征
selector = SelectKBest(score_func=f_classif, k=5)
X_selected = selector.fit_transform(X, y)

# 查看每个特征的得分
scores = selector.scores_
for i, score in enumerate(scores):
    print(f"特征 {i}: {score:.1f}")
```

### 特征组合

```python
# 多项式特征：生成特征的交互项
from sklearn.preprocessing import PolynomialFeatures

X = np.array([[1, 2], [3, 4]])
poly = PolynomialFeatures(degree=2, include_bias=False)
X_poly = poly.fit_transform(X)
print(f"原始: {X.shape} → 多项式: {X_poly.shape}")
# 生成: [x1, x2, x1², x1·x2, x2²]
```
