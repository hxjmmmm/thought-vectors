## 什么是机器学习？

Tom Mitchell (1998) 的定义：

> 一个计算机程序从经验 E 中学习，解决任务 T，性能度量 P。当且仅当有了经验 E 后，程序在任务 T 上的性能 P 随之提升。

通俗地说：**让机器从数据中自动发现规律，而不是人工编写规则**。

### 三种学习范式

| 范式 | 数据 | 目标 | 例子 |
|------|------|------|------|
| 监督学习 | 有标签 (x, y) | 学习 x→y 的映射 | 分类、回归 |
| 无监督学习 | 无标签 (x) | 发现数据中的结构 | 聚类、降维 |
| 强化学习 | 环境交互 | 最大化累积奖励 | 游戏、机器人 |

### 线性回归：最简单的例子

给定房屋面积，预测价格。模型假设：

$$
y = wx + b
$$

其中 $w$ 是权重，$b$ 是偏置。学习的目标是找到最优的 $w$ 和 $b$。

```python
import numpy as np

# 数据：房屋面积 (m²) 和价格 (万元)
X = np.array([50, 60, 80, 100, 120, 150])
y = np.array([150, 180, 240, 300, 360, 450])

# 最小二乘法：解析解
X_b = np.c_[np.ones((len(X), 1)), X]  # 加偏置列
w = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y

print(f"w0 (偏置) = {w[0]:.1f}, w1 (权重) = {w[1]:.1f}")
# 输出: w0 (偏置) = 0.0, w1 (权重) ≈ 3.0
# 模型: 价格 ≈ 3 × 面积

# 预测
area_new = 90
price = w[0] + w[1] * area_new
print(f"面积 {area_new}m² 的预测价格: {price:.0f} 万元")
```

### 梯度下降：当数据量大时

当数据量巨大时，解析解计算量太大。梯度下降每次用一小步更新参数：

$$
w := w - \alpha \frac{\partial L}{\partial w}
$$

其中 $\alpha$ 是学习率，$L$ 是损失函数。

```python
# 梯度下降实现线性回归
w, b = 0.0, 0.0
lr = 0.0001
epochs = 1000

for epoch in range(epochs):
    # 预测
    y_pred = w * X + b
    # 均方误差
    loss = np.mean((y_pred - y) ** 2)
    # 梯度
    dw = np.mean(2 * (y_pred - y) * X)
    db = np.mean(2 * (y_pred - y))
    # 更新
    w -= lr * dw
    b -= lr * db

    if epoch % 200 == 0:
        print(f"Epoch {epoch}: loss={loss:.1f}, w={w:.2f}, b={b:.1f}")

print(f"\n最终模型: y = {w:.2f}x + {b:.1f}")
```

### 过拟合与欠拟合

| 现象 | 表现 | 原因 | 解决 |
|------|------|------|------|
| 欠拟合 | 训练集上表现就差 | 模型太简单 | 增加特征、复杂度 |
| 过拟合 | 训练集好，测试集差 | 模型太复杂 | 正则化、更多数据 |

$$
\text{过拟合的标志：} \quad \text{训练误差} \ll \text{测试误差}
$$
