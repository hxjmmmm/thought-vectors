## 数学基础

机器学习本质上是数学。掌握三个核心领域，就能理解大部分算法。

### 线性代数：数据的语言

数据在机器学习中表示为向量和矩阵。

#### 向量

```python
import numpy as np

# 向量：一维数组
v = np.array([1, 2, 3])
u = np.array([4, 5, 6])

# 点积
dot = np.dot(v, u)  # 1×4 + 2×5 + 3×6 = 32
print(f"点积: {dot}")

# 范数（长度）
norm = np.linalg.norm(v)  # √(1²+2²+3²) ≈ 3.74
print(f"L2 范数: {norm:.2f}")
```

#### 矩阵运算

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

# 矩阵乘法
C = A @ B  # [[1×5+2×7, 1×6+2×8], [3×5+4×7, 3×6+4×8]]
print(f"A @ B =\n{C}")

# 转置
print(f"A^T =\n{A.T}")

# 逆矩阵
A_inv = np.linalg.inv(A)
print(f"A⁻¹ =\n{A_inv}")
print(f"A × A⁻¹ =\n{A @ A_inv}")  # 单位矩阵
```

#### 特征值与特征向量

$$A v = \lambda v$$

```python
eigenvalues, eigenvectors = np.linalg.eig(A)
print(f"特征值: {eigenvalues}")
print(f"特征向量:\n{eigenvectors}")
```

### 概率论：不确定性的数学

#### 基本概念

```python
# 概率分布
p = np.array([0.2, 0.3, 0.5])  # 三个事件的概率，和为 1

# 期望值
x = np.array([1, 2, 3])
expectation = np.sum(p * x)
print(f"期望值: {expectation}")
```

#### 正态分布

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

```python
import matplotlib.pyplot as plt

# 标准正态分布
x = np.linspace(-4, 4, 100)
y = (1 / np.sqrt(2 * np.pi)) * np.exp(-x**2 / 2)

plt.plot(x, y)
plt.axvline(0, color='red', linestyle='--', label='μ=0')
plt.fill_between(x[x > -1], y[x > -1], 0, alpha=0.1, color='blue')
plt.title('标准正态分布 N(0, 1)')
plt.show()
```

### 微积分：优化的基础

#### 导数

导数是函数在某点的变化率，梯度下降依赖导数来更新参数：

$$
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
$$

```python
# 数值微分
def derivative(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)

f = lambda x: x**3 + 2*x
print(f"f'(2) = {derivative(f, 2):.4f}")  # 3×4 + 2 = 14
```

#### 偏导数与梯度

多变量函数对每个变量分别求导，得到梯度向量：

$$
\nabla f = \left[\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, ..., \frac{\partial f}{\partial x_n}\right]
$$

```python
# 梯度下降演示
def gradient_descent(f_grad, start, lr=0.1, steps=50):
    x = start
    path = [x]
    for _ in range(steps):
        grad = f_grad(x)
        x = x - lr * grad
        path.append(x)
    return path

# f(x) = x² 的最小值（显然在 x=0）
f = lambda x: x**2
f_grad = lambda x: 2*x

path = gradient_descent(f_grad, start=5.0)
print(f"起点: {path[0]:.1f}, 终点: {path[-1]:.4f}")
```
