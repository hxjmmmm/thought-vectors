## Python 机器学习工具链

### NumPy：数值计算基石

```python
import numpy as np

# 创建数组
arr = np.array([1, 2, 3, 4, 5])
matrix = np.array([[1, 2], [3, 4]])

# 运算
print(arr * 2)           # [2 4 6 8 10]
print(arr @ arr)         # 点积 = 55
print(matrix.T)          # 转置
print(np.linalg.inv(matrix))  # 逆矩阵

# 常用函数
print(np.mean(arr), np.std(arr))  # 均值、标准差
print(np.random.randn(3, 3))     # 随机矩阵
```

### Pandas：数据处理

```python
import pandas as pd

# 读取数据
df = pd.read_csv("data.csv")

# 基本操作
print(df.head())
print(df.describe())        # 统计摘要
print(df["column"].mean())  # 单列均值
print(df.isnull().sum())    # 缺失值统计

# 数据清洗
df = df.dropna()                    # 删除缺失值
df = df[df["price"] > 0]           # 过滤异常值
df["category"] = df["cat"].map({    # 编码
    1: "A", 2: "B", 3: "C"
})
```

### Matplotlib：数据可视化

```python
import matplotlib.pyplot as plt

# 散点图
x = np.random.randn(100)
y = 2 * x + np.random.randn(100) * 0.5
plt.scatter(x, y, alpha=0.6)
plt.xlabel("X")
plt.ylabel("Y")
plt.title("Scatter Plot")
plt.show()

# 直方图
plt.hist(np.random.randn(1000), bins=30)
plt.show()
```
