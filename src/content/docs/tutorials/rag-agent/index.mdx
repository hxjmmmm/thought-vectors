## RAG 与 Agent 开发

本系列教程讲解如何构建实际的 AI 应用，包括 RAG 系统和 Agent。

### 你将学到

- RAG 架构：检索、增强、生成的完整流程
- 向量数据库：Chroma、Pinecone、Milvus
- 文档处理：切分策略、嵌入模型选择
- Agent 框架：LangChain、LlamaIndex
- 工具调用（Function Calling）
- 多步推理和记忆系统
- 实战项目：构建一个知识问答机器人

### 前置知识

- Python 基础
- 了解 LLM 的基本使用
