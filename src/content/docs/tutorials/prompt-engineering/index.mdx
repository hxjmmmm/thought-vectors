## Prompt Engineering 指南

Prompt Engineering 是使用大模型的核心技能。本教程从基础到高级，教你如何写出高质量提示词。

### 你将学到

- 提示词的基本结构
- Few-shot、Zero-shot 提示
- Chain-of-Thought（思维链）推理
- 角色扮演和系统提示
- 结构化输出（JSON、表格）
- 提示词模板和工程化

### 前置知识

- 了解大模型的基本概念
- 有使用 ChatGPT/Claude 的经验
